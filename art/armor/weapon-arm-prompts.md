# Weapon-arm artwork

Generated with the built-in ImageGen tool. Each sprite is stored as a lossless WebP alongside its chest armor. The base fighter and each set's chest sprite supplied the pose and style references. Placement and animation use the existing fighter rig.

## court/upper-arm.webp

Use case: stylized-concept. Asset type: one independent wearable 2D armor sprite for The Cinder League.
Reference image 1 is the base fighter, used ONLY for the precise three-quarter right-facing angle and weapon-arm anatomy. Reference image 2 is the matching chest armor, used for exact materials, ink outline, gold edge thickness, lighting and painted cartoon RPG style.
Draw ONLY this single independent armor object, with no wearer: A single short armored upper-arm sleeve, from beneath an existing pauldron to the elbow. Orient nearly vertically, broad top at screen-right and slightly narrower bottom a little to screen-left. Include dark navy padded inner sleeve and polished overlapping silver lames with restrained gold trim. No shoulder pauldron, no forearm, no hand.
Fully opaque armor with genuinely alpha-transparent exterior, empty openings where appropriate. Single uncropped object, slim margin. No human skin, text, watermark, sword, background, drop shadow or other parts. Match the supplied cartoon artwork, not a photo or 3D render.
